## 👋 Sobre mí

Soy **Analista de Datos** con una base sólida en **Contaduría Pública** (IPN · ESCA Tepepan, 10° semestre) y formación especializada en análisis de datos a través del **Bootcamp TripleTen** — un programa de intensidad equivalente a una maestría aplicada.

Mi diferencial: combino el **pensamiento financiero y de negocio** de un contador con las **herramientas técnicas de un analista de datos moderno**. No solo genero reportes — transformo datos en decisiones accionables con impacto directo en resultados de negocio.
